Features · Functies

  • Reads and writes RDCMan .rdg files
  • Dynamic resolution: the session follows the pane or window
  • Multi-view: a grid of panes, each with its own tabs
  • Experience settings as in mstsc, keep session active
  • Groups linked to an Active Directory OU
  • Password vault (optional), bound to approved hosts
  • Routes via Tailscale or an RD Gateway
  • Reachability check, Wake-on-LAN, light/dark theme
  • Leest en schrijft RDCMan-bestanden (.rdg)
  • Dynamische resolutie: de sessie volgt het vak of venster
  • Multi-view: een raster van vakken, elk met eigen tabs
  • Gebruikerservaring zoals mstsc, sessie actief houden
  • Groepen gekoppeld aan een Active Directory-OU
  • Wachtwoordkluis (optioneel), gebonden aan goedgekeurde hosts
  • Routes via Tailscale of een RD Gateway
  • Bereikbaarheid, Wake-on-LAN, licht/donker thema
